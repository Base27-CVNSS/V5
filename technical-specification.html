01 / Status and definitions

Research software, not yet a production DGGS

Technical accuracy takes precedence over an attractive feature list. The statements below are classified by actual maturity.

Implemented / proved (weak)

32-child nested prototype

Five binary bent-crosscut subdivisions yield exactly 32 strict simple, potentially concave pentagons. Spherical radial projection preserves weak coverage and containment.

Implemented

Canonical UInt64 address

Version, resolution, root and ten left-aligned base-32 path slots support encode / decode / parent / children in Python.

Open mathematics

Strong conforming refinement

Strictly convex spherical children, cross-parent edge conformity, uniform shape regularity and a certified global one-step contraction are not established.

Not implemented

Operational spatial engine

Global WGS84 point lookup, geographic adjacency, polygon coverings, GPU kernels and measured speedups have no shipped verified implementation.

Important: A five-sided cell is not equivalent to a five-child tree. V5-32 uses 32 children encoded by 5-bit child digits. It is not a 5-ary hierarchy.
02 / Verified mathematical principles

Spherical curvature and topological restrictions

Girard–Gauss–Bonnet

For a nondegenerate positively oriented geodesic spherical pentagon on a sphere of radius R, the sum of interior angles exceeds 3π:

Σ αᵢ − 3π = A/R² > 0

At every ordinary vertex in a gapless partition of the smooth sphere, the incident sector angles sum to 2π. Neither condition proves existence of any given 32-child tiling.

No nontrivial metric similarity

For open subsets of the same round sphere, a local diffeomorphism satisfying f* g = λ²g with constant λ>0 must have λ=1, since both domains have curvature 1/R² while scaling the metric divides curvature by λ².

1/R² = 1/(λ²R²) ⟹ λ = 1
Impossibility applies to exact Riemannian homothety, not to the weaker target diam(child) ≤ ρ · diam(parent) with ρ<1. That target needs an independent constructive proof.

Euler and boundary parity

V − E + F = 2;  5F = 2E;  Σ(deg(v) − 3) = F/2 − 6

For 32 edge-to-edge pentagonal children, 160 = 2I+B. Therefore the number B of boundary child-edge segments must be even. Five wholly unsplit outer edges cannot suffice.

Optional research extension / Spatial DNA v0.1

77.4% entropy capacity is a five-way codec limitation, not V5-32.

The expression log₂(5)/3 ≈ 77.4% refers to a hypothetical five-child tree stored with three bits per digit. Fifteen levels take 45 fixed-width bits, whereas a lossless dense base-five rank fits in 35 bits, releasing only 10 physical bits after repacking. The actual V5-32 uses all 32 values of a five-bit digit and has 100% maximum digit-alphabet capacity; its canonical padding MUST NOT carry metadata.

Implemented experimental prototype

Signed epigenetic sidecar

The new src/v5dna.py format is an optional 54-byte sidecar combining the unchanged V5-64 ID, atlas reference, epoch, per-level 2-bit annotations, CRC32 accidental-error detection and HMAC-SHA256/128 authentication.

Security and recovery not provided

Crypto, ECC, ACL and history are separate

A 15-bit tag is too short. CRC is not error correction; an HMAC is not encryption, a public-key signature, trusted geographic provenance or an access-control mechanism. Real recovery requires snapshots/parity/FEC and verified restoration.

06 / Geodesy and spatial operations

The missing geographic reference contract

A production V5 atlas MUST freeze the sphere/ellipsoid reference model, global dodecahedron rotation, root labels, polygon vertex order, child geometry, seam ownership and numerical precision. The current sample root is a planar mathematical demonstration, not an Earth-fixed atlas.

Required geographic pipeline

  1. Validate WGS84 latitude/longitude and resolution.
  2. Transform to the explicitly selected reference surface.
  3. Select canonical root cell and child path.
  4. Resolve exact boundary-owner rules.
  5. Return packed V5-64 plus reproducible geometry metadata.

Neighbor topology

Five geometric sides do not always imply exactly five adjacent cells when hanging nodes exist. Define edge-neighbors, vertex-neighbors, parent/child relations and global seam behavior separately.

A production implementation MUST certify reciprocity and shared-boundary geometry before offering neighbor APIs.

08 / GeoAI · World Models

Train spatial models without assuming equal-area cells

Hierarchical spatial tokens

Use a root token and 5-bit base-32 digit embeddings for multiresolution encoding. Combine with attributes, observation dates and sensor provenance. Avoid dense one-hot vectors over every high-resolution global cell.

Actual graph topology

Use sparse COO/CSR graph edges derived from verified cell intersections. Padded five-neighbor tensors should not be applied to the nonconforming weak prototype.

Area-weighted objectives

L = (Σ Aᵢ ℓᵢ) / (Σ Aᵢ)

Useful when estimating an area integral over cells with unequal surface areas; not a universal optimal AI loss.

Space-time and Entities

CellID captures a spatial hierarchy only. Keep observation timestamps, object trajectories and persistent EntityIDs in separate schemas; an encoded cell address is not encryption.
